# The Freedom Blueprint — Interactive Course

**From corporate salary to independent income in 12 months.**

A comprehensive, interactive web course with calculators, planners, and tools — based on *The Freedom Blueprint* by Ammar Aldaas.

## What's Inside

- **Freedom Number Calculator** — Find your real monthly target
- **Energy Audit Tool** — Discover your peak cognitive hours  
- **Buffer Architecture Planner** — Engineer your financial safety net
- **Product Decision Matrix** — Find the right product to build
- **Validation Scorecard** — Score your idea before you build
- **7-Day Sprint Planner** — Ship your first product in one week
- **90-Day Launch Timeline** — Week-by-week revenue system
- **Revenue Stack Builder** — Design your income portfolio
- **Contract Audit Checklist** — Legal protection before you build
- **Fear Engineering Manual** — Deconstruct every anxiety
- **Five Signals Dashboard** — Track your measurable quit criteria
- **365-Day Retrospective** — Your annual operating review

## Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. Start at Chapter 1

No build tools required. Works directly on GitHub Pages.

## Deploy to GitHub Pages

1. Push to your GitHub repository
2. Go to Settings → Pages
3. Set source to `main` branch, root folder
4. Your course is live at `https://yourusername.github.io/freedom-blueprint-course/`
